# Cursor

This repo only tracks Cursor AI-related assets that are not covered well by Cursor's built-in sync.

Tracked:

- `mcp.json`

Not tracked:

- `settings.json`
- `keybindings.json`
- extensions
- projects
- runtime state

If you later add custom Cursor AI assets such as `skills/`, `rules/`, or `commands/`, keep them here and extend `scripts/bootstrap.sh` accordingly.
